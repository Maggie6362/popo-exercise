# 婆婆與阿凱的健康運動打卡 (Web App)

專為 82 歲婆婆量身規劃的運動打卡小工具，搭配孫子「阿凱」的 3D 卡通立體公仔圖示與真實激勵語音。

## 🌟 核心特色
1. **極簡大字體、超大觸控按鈕**：整張運動卡片輕點即可打卡，長輩操作零障礙。
2. **阿凱真實錄音互動 (5段情境音效)**：
   - 01_早安問候：打開 App 陪婆婆動一動
   - 02_完成單項：每打卡一項立即稱讚
   - 03_加油鼓勵：運動量不足時溫柔打氣
   - 04_達標比雙讚：完成 2~3 項達標時稱讚
   - 05_超標抱愛心：活力滿滿時叮嚀多喝溫水休息
3. **影片示範引導教學**：針對原地踏步、椅子起坐、扶椅墊腳尖等動作，內建專屬教學示範按鈕。
4. **雙人雙模式切換**：
   - 「阿嬤打卡模式」：大字、大圖、直覺打卡。
   - 「女兒關懷模式」：即時查看母親今日達成率、本週運動歷史紀錄。
5. **跨 iPhone 即時同步支援**：
   - 預設具備離線自動儲存（LocalStorage）。
   - 內建 Supabase 雲端資料庫串接介面，兩支手機連動零延遲。

## 🚀 部署到 iPhone 步驟 (GitHub Pages)
1. 將本資料夾所有檔案推送到您的 GitHub Repository (例如: `popo-exercise`)。
2. 在 GitHub Repo 的 **Settings -> Pages** 中，Source 選擇 `Deploy from a branch` -> `main` / `root` -> 點擊 **Save**。
3. 取得部署網址後，分別在婆婆與您的 iPhone 上使用 Safari 開啟該網址。
4. 點擊 Safari 下方的 **「分享」按鈕 (箭頭向上圖示)** -> 選擇 **「加入主畫面」**。
5. 手機桌面上即會生成戴黑框眼鏡的「3D 阿凱頭像」專屬 App 圖示，點擊即可全螢幕使用！
